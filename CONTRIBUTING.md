# Contributing Guide For agent-context-sdk

This page lists the operational governance model of this project, as well as
the recommendations and requirements for how to engage with it.

# Governance Model

## Published but not supported

`agent-context-sdk` is published under the Salesforce Public Code License
(see [LICENSE.txt](LICENSE.txt)) so customers can read, install, and use the
SDK with Salesforce services. Salesforce maintains it, but we are not looking
for or soliciting code contributions, and pull requests will generally not be
merged.

# Issues, requests & ideas

Use the GitHub [Issues](https://github.com/salesforce-misc/agent-context-sdk/issues)
page to report bugs or request enhancements. Please search existing issues
first, and include enough detail (SDK version, Python version, framework and
adapter, and a minimal reproduction) for us to reproduce the problem.

Do not report security issues in GitHub Issues — see [SECURITY.md](SECURITY.md).

Please follow our [Code of Conduct](CODE_OF_CONDUCT.md).
